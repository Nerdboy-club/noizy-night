# Operation: Silent Night — Roblox

Кооперативная стелс-комедия про эльфов Санты. Порт на Roblox (Luau + Rojo), весь мир строится
кодом из блоков, поэтому игра запускается из пустого места без ручной расстановки.

**Важно:** код ни разу не запускался в Studio. Перед публикацией его нужно прогнать по чек-листу
ниже и прислать красные строки из Output.

## Цикл игры

1. **Лобби.** Игрок встаёт на площадку «Соло / Дуэт / Трио / Отряд». Отсчёт 10 с, при полной
   площадке 3 с. В опубликованной игре команда уезжает на свой отдельный сервер, в Studio смена
   идёт на том же сервере.
2. **Мастерская.** Доска заказов (3 адреса, иногда «жуткий дом» ×2), конвейер с подарками, сани,
   верстак с прокачкой и скинами, дверь обратно в лобби.
3. **Крыши.** 15 пронумерованных труб, прыжки, снежные пандусы, лёд. Нужна труба из адреса заказа.
4. **Дом.** 6 комнат, Дед, кот, скрипучие двери и половицы, игрушки на полу. Подарки разлетелись
   по дому: собрать под ёлку и уйти через камин.
5. **Итог.** Звание, смешные строки, чаевые. Потом снова мастерская.

## Что поставить на ПК для проверки

1. **Roblox Studio** — https://create.roblox.com (нужен аккаунт Roblox).
2. **Rojo 7**, любой способ с https://rojo.space/docs/v7/getting-started/installation/ :
   - готовый файл со страницы https://github.com/rojo-rbx/rojo/releases , положить в папку из `PATH`;
   - через Rokit: `rokit add rojo-rbx/rojo`, затем `rokit install`;
   - через Rust: `cargo install rojo --version ^7`.
3. **Плагин Rojo для Studio**: команда `rojo plugin install` или кнопка Install на
   https://www.roblox.com/library/13916111004/Rojo .

## Запуск для проверки

1. В терминале, из папки `roblox/`:
   ```
   rojo serve
   ```
2. В Studio создать место по шаблону **Baseplate**.
3. Вкладка **Plugins** → **Rojo** → **Connect**.
4. Нажать **Play** (F5), открыть **View → Output**. Должна появиться строка
   `[SilentNight] Server started: world built, all services running.`
   Жёлтые и красные строки со словом `SilentNight`, `failed` или с путём к скрипту — копировать и присылать.

Кооператив: вкладка **Test** → **Clients and Servers** → 2 Players → **Start**.

## Управление

| Клавиша | Действие |
|---|---|
| WASD, мышь, пробел | ходьба, камера, прыжок |
| Shift (удерживать) | бег, тратит силы |
| C | красться (переключатель); под столом и кроватью Дед не видит |
| E | взять / положить, станции, поднять друга, трубы |
| R | убрать подарок в мешок / достать |
| F | бросить кошачью мяту |
| Q (удерживать) | реактивный ранец (после покупки на верстаке) |

## Чек-лист проверки

Лобби и мастерская
- [ ] Игрок появляется в снежном лобби, над площадками подписи «Соло 0/1» и т. д.
- [ ] Встал на «Соло»: отсчёт, перенос в мастерскую.
- [ ] «Шкаф и магазин» в лобби и верстак в мастерской открывают панель; покупка за чаевые работает.
- [ ] На доске три заказа, после выбора из люка по конвейеру едут подарки.
- [ ] Подарок берётся на E, мелкие убираются в мешок на R, у саней на E грузятся; счётчик «Сани: N/M».
- [ ] После погрузки всех подарков сани отправляют на крыши.

Крыши
- [ ] Трубы с номерами, чужая труба пишет «Не тот адрес», нужная переносит в дом.
- [ ] Падение с крыши возвращает на первую крышу.

Дом
- [ ] Шесть комнат, две двери качаются; на бегу дверь хлопает («БАХ!»).
- [ ] Спринт лбом в стену и шаг на игрушку роняют эльфа, он встаёт сам.
- [ ] Дед: Zzz → … → ? → ?? → !, встаёт, идёт на шум, осматривается, возвращается.
- [ ] Под столом в приседе надпись «Спрятались», Дед проходит мимо.
- [ ] Кот бродит, орёт, если наступить на хвост не крадучись; мята [F] его отвлекает.
- [ ] Снежный шар бьётся при падении, шкатулка звенит, машинка уезжает, игрушка тикает.
- [ ] Велосипед несётся медленно; второй игрок может взяться на E, вдвоём быстрее.
- [ ] Все подарки под ёлкой → «Уйти через дымоход» → экран результатов → мастерская.
- [ ] Поимка: в одиночку «Пойманы!», в коопе эльфа выкидывает к камину и друг поднимает его на E.

Сохранение
- [ ] После рейса выйти и зайти снова: чаевые и прокачка на месте (в Studio нужна настройка из раздела ниже).

## Публикация

1. В Studio с подключённым Rojo: **File → Publish to Roblox**, создать новый experience.
2. **File → Game Settings** (названия пунктов могут немного отличаться в новой Studio):
   - **Security → Enable Studio Access to API Services** — включить, иначе в Studio не работает сохранение.
   - **Avatar → Avatar Type: R15**.
   - **Places → максимум игроков**: 16 (это размер лобби; отряды уезжают на свои серверы).
   - **Permissions → Public**, когда готовы открыть игру.
3. В Creator Dashboard заполнить анкету возрастного рейтинга (Maturity & Compliance), без неё игра
   не станет публичной. Содержимое: мультяшное, без крови, погоня без насилия.
4. Телепорт команды на отдельный сервер работает только в опубликованной игре, не в Studio.
   Проверка: зайти в игру через сайт Roblox вдвоём и встать на «Дуэт».

После каждой правки кода: снова **Publish to Roblox**.

## Платное (Robux)

В `src/shared/Config.luau` всё платное выключено, пока `Id = 0`: кнопки показывают «Скоро».

| Что | Тип в Roblox | Что даёт |
|---|---|---|
| VIP-эльф | Game Pass | чаевые за рейс ×1.5, значок VIP над головой |
| Золотой эльф | Game Pass | светящийся золотой скин |
| Мешочек чаевых | Developer Product | +500 чаевых |
| Сундук чаевых | Developer Product | +2000 чаевых |

Как включить:
1. Creator Dashboard → ваш experience → **Monetization** → **Passes** и **Developer Products**:
   создать четыре позиции, назначить цены в Robux.
2. Скопировать числовые ID и вписать в `Config.GamePasses.*.Id` и `Config.Products.*.Id`.
3. Опубликовать заново.

Бесплатно за чаевые: вся прокачка, мята и скины «Снежный», «Карамельный», «Лесной», «Ночной ниндзя».
Случайных призов за Robux (лутбоксов) в игре нет, это избавляет от требований Roblox к раскрытию шансов.

## Что упрощено по сравнению с Unity-версией

- Присед — опускание бёдер без анимации; карабканья нет (хватает прыжка).
- Бесшумные ботинки снижают шум шагов, но скольжение на льду не меняют.
- Нет телевизора с пультом, батута, split-screen HUD.
- Дед, кот, мебель и подарки — блоки; модели ставятся позже через импорт в Studio.
- В Studio одновременно идёт только одна смена на сервер.

## Где что лежит

- `default.project.json` — раскладка Rojo.
- `src/shared/Config.luau` — все числа, цены, скины, ID платных товаров.
- `src/server/World/` — строители мира: `LobbyBuilder`, `HubBuilder`, `RooftopBuilder`, `HouseBuilder`.
- `src/server/Services/` — по одному сервису на файл: `MissionService` (ход смены), `LobbyService`,
  `HubService`, `RooftopService`, `ElfService`, `GiftService`, `GrandpaService`, `CatService`,
  `DoorService`, `NoiseService`, `ProfileService` (сохранение), `MonetizationService`, `SkinService`.
- `src/client/Controllers/` — `InputController`, `HudController`, `ShopController`.
